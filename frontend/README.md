# 🐟 摸鱼计算器

> 你摸的不是鱼，是真金白银 💸

打工人 · 精神股东 · 必备神器。输入月薪，实时计算你每一秒摸鱼赚（白嫖）了老板多少钱。

## ✨ 功能

- **⚙️ 报上家底**：填入月薪 / 每天工时 / 每月工作日，自动算出时薪、分钟薪、秒薪
- **💰 实时计费**：开始摸鱼后金额按秒实时跳动，可"假装工作"暂停、收工结账
- **💱 白嫖换算**：这趟摸鱼相当于多少杯奶茶 🧋、几份 V 我 50 🍗、几顿火锅 🍲、几个传说皮肤 🎮
- **📊 今日战报**：累计今日摸鱼收入（数据存在浏览器 localStorage，仅当天有效）
- **🏆 摸鱼段位**：从鱼苗 🐟 一路摸到摸鱼龙王 🐉，带晋级进度条
- **📖 摸鱼圣经**：随机抽取打工人摸鱼语录

## 🛠 技术栈

- React 18 + TypeScript + Vite
- Tailwind CSS + shadcn/ui
- 新粗野主义（Neo-Brutalism）撞色设计

## 🚀 本地运行

```bash
npm install
npm run dev
```

## 📦 构建

```bash
npm run build
```

产物在 `dist/`，为纯静态文件，可直接部署到 GitHub Pages / Vercel / Netlify 等任意静态托管。
