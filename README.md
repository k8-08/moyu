## 📖 项目简介

**摸鱼计算器** 是一套专为当代职场“打工人/精神股东”量身定制的沉浸式全栈应用。它结合了科学的薪资折算模型与风趣幽默的职场文化，旨在将枯燥的工位时间游戏化、具象化。

系统采用现代化前后端分离架构：
- **前端**：采用 **React 19 + Vite 7 + TypeScript** 构建，视觉上深度应用**新野兽派 (Neo-Brutalism) 与波普 (Pop-Art)** 风格设计，鲜活的高饱和对比色、3px 实心黑边框、硬阴影、动态跑马灯与时间滚轮组件带来强烈的视觉冲击。
- **后端**：基于 **Python FastAPI + SQLAlchemy 2.0 + MySQL 8.0**，提供极速响应的 RESTful API，配备 Pillow 动态防机器人验证码、JWT 长效免密机制及多维统计聚合引擎。

无论你是想要在工位上实时看着薪资数字跳动、精准记录带薪蹲坑收益，还是管理员想要以幽默的方式俯瞰团队整体的工时与摸鱼大盘，本系统都能完美胜任。

- **摸鱼战神英雄榜 (TOP 10)**：自动排行出摸鱼白嫖收益最高、战力最强的工位战神。

- **每日工资快照流水归档**：按日期、员工筛选归档历史流水，支持历史异常记录自动纠偏。

### 5. 🛡️ 安全认证与长效免密
- **Pillow 防机器人图形验证码**：本地动态生成含噪点、干扰线与随机扭曲字符的验证码，防止爆破与刷单。
- **30天设备绑定长效免密**：前端自动生成唯一设备标识 `X-Device-Id`，结合 JWT Bearer Token 实现长达 30 天的无感自动登录与设备续期。
- **Bcrypt 密码安全加盐哈希**：彻底保障账户隐私与凭证安全。
- **一键预置超级管理员**：服务启动时自动初始化默认管理员账号。

## 🧮 薪资与工时数学计算模型

系统严格依据法定劳动计算法则与实际上下班打卡时段进行精细化拆解：

### 1. 每日有效工时计算
扣除午休时段后，实际每日有效劳动秒数 $T_{\text{work}}$ 为：
$$T_{\text{work}} = \Big(T_{\text{work\_end}} - T_{\text{work\_start}}\Big) - \Big(T_{\text{lunch\_end}} - T_{\text{lunch\_start}}\Big)$$

### 2. 薪资基准折算公式
- **每日出勤底薪**（基准保底工资）：
  $$\text{Daily Base} = \frac{\text{Salary (月薪)}}{\text{Work Days (月计薪天数)}}$$
  *(中国法定月计薪天数默认为 21.75 天)*
- **每秒薪资变现率**：
  $$\text{Rate}_{\text{second}} = \frac{\text{Salary}}{\text{Work Days} \times T_{\text{work}} \times 3600}$$
- **每分薪资变现率**：
  $$\text{Rate}_{\text{minute}} = \text{Rate}_{\text{second}} \times 60$$
- **每小时薪资变现率**：
  $$\text{Rate}_{\text{hour}} = \text{Rate}_{\text{second}} \times 3600$$

### 3. 摸鱼白嫖收益与总收益
- 单次摸鱼收益：
  $$\text{Slack Earned} = \text{Duration (秒)} \times \text{Rate}_{\text{second}}$$
- 当日已赚总收益：
  $$\text{Total Daily Earned} = \text{Daily Base} + \sum \text{Slack Earned}$$

## 🗄️ 数据模型设计

| `duration` | INT | NOT NULL | 持续时长 (秒) |

| `created_at` | DATETIME | NOT NULL, INDEX | 记录创建时间 |

### 4. 每日工资快照表 (`daily_salaries`)
| 字段名 | 类型 | 约束 / 索引 | 说明 |
| :--- | :--- | :--- | :--- |
| `id` | INT | PK, 自增 | 快照 ID |
| `user_id` | INT | FK -> users.id, INDEX | 所属打工人 |
| `date` | VARCHAR(10) | INDEX | 日期 (`YYYY-MM-DD`) |
| `year` / `month` / `week` / `day` | INT | INDEX | 多维聚合筛选时间维度字段 |
| `base_salary`| FLOAT | 默认 0.0 | 今日实际出勤基本保底工资 |
| `slack_salary`| FLOAT | 默认 0.0 | 今日摸鱼累计白嫖总额 |
| `total_salary`| FLOAT | 默认 0.0 | 今日已赚总收益 (底薪 + 摸鱼) |
| `slack_count` | INT | 默认 0 | 今日摸鱼总频次 |
| `slack_duration`| INT | 默认 0 | 今日摸鱼累计总秒数 |
| `updated_at` | DATETIME | NOT NULL | 结算单最后上报更新时间 |

> 📌 **联合唯一索引**：`(user_id, date)` 保证每个用户每天对应一条权威工资结算快照，上报时执行 Upsert（存在则更新，不存在则插入）。

## 🔌 API 接口规范全览

默认 API 根前缀为 `/api`，支持通过交互式 Swagger 文档在线调试：`http://localhost:8080/api/docs`。

### 1. 认证与授权 (`/api/auth`)
- `GET  /api/auth/captcha`：获取防脚本注册图形验证码（返回 base64 图片及 `captcha_id`）。
- `POST /api/auth/register`：打工人注册账号（校验图形验证码、一致性校验、自动初始化默认打工档案）。
- `POST /api/auth/login`：账号登录（验证凭证、更新设备 `device_id`、返回 30 天有效期的 JWT Token）。
- `GET  /api/auth/me`：根据 Bearer Token 获取当前登录用户信息（用于前端免密状态恢复）。

### 2. 打工档案 (`/api/profile`)
- `GET  /api/profile`：获取当前登录用户的打工薪酬作息档案。
- `PUT  /api/profile`：更新打工档案（月薪、工时、午休时段等），并联动重新计算并同步更新当天的日薪底薪。

### 3. 摸鱼明细记录 (`/api/records`)
- `GET    /api/records?date_str=YYYY-MM-DD`：获取指定日期或当天的摸鱼流水明细列表。
- `POST   /api/records`：新增一条摸鱼记录（录入分类、起止时间、秒数与白嫖金额）。
- `DELETE /api/records/{record_id}`：“毁尸灭迹” —— 销毁指定 ID 的摸鱼罪证。

### 4. 每日工资表结算 (`/api/salary`)
- `POST /api/salary/report`：客户端上报/同步今日工资结算快照（包含出勤保底、摸鱼总额与频次时长）。
- `GET  /api/salary/my-history?year=2026&month=9&limit=100`：获取当前打工人的历史每日结算快照。

### 5. 后台管理与监控看板 (`/api/admin` - 需 Admin 权限)
- `GET /api/admin/stats?dimension=(day|week|month|year|all)`：查询多维度的公司宏观大盘数据（底薪开支、摸鱼总额、摸鱼分类排行、战神榜 Top 10、全员明细）。
- `GET /api/admin/users`：获取全公司所有打工人账号列表、基础档案与历史累计摸鱼收益。
- `GET /api/admin/salaries?user_id=1&year=2026&month=9`：分页查询全员每日工资表快照流水（支持自动数据校验与底薪兜底修复）。

## 🚀 生产部署实战指南

### 方案 A：宝塔面板部署 (强烈推荐，省心快捷)

#### 第一步：创建 MySQL 数据库
1. 登录宝塔面板，进入【数据库】。
2. 添加数据库，数据库名填写 `moyu_db`，编码选择 `utf8mb4`，记录下数据库用户名与密码。

#### 第二步：部署后端 API (Python 项目管理器)
1. 将项目的 `backend` 目录上传到宝塔服务器（例如 `/www/wwwroot/moyu-backend`）。
2. 在宝塔项目根目录下重命名 `.env.example` 为 `.env`，修改连接配置：
   ```env
   PROJECT_NAME="摸鱼计算器API"
   VERSION="1.0.0"
   API_V1_STR="/api"
   MYSQL_SERVER="127.0.0.1"
   MYSQL_PORT=3306
   MYSQL_USER="你的宝塔数据库用户"
   MYSQL_PASSWORD="你的宝塔数据库密码"
   MYSQL_DB="moyu_db"
   SECRET_KEY="请生成并填入一个强随机字符串"
   ACCESS_TOKEN_EXPIRE_DAYS=30
   ```
3. 在宝塔面板左侧打开【网站】->【Python 项目】：
   - **项目名称**：`moyu-api`
   - **路径**：`/www/wwwroot/moyu-backend`
   - **Python 版本**：选择 Python 3.10+
   - **框架**：`FastAPI`
   - **启动文件/启动模块**：`main.py`
   - **启动方式**：`python main.py` 或选择 `uvicorn` 运行 `main:app --host 127.0.0.1 --port 8080`
   - **端口**：`8080`
   - 勾选安装 `requirements.txt` 内的依赖。
4. 启动项目，查看运行日志确认输出 `>>> 默认管理员已初始化: admin / admin123`。

#### 第三步：构建与部署前端静态站点 (Nginx)
1. 在本地或服务器的 `frontend` 目录执行打包命令：
   ```bash
   cd frontend
   npm run build
   ```
   命令执行完毕后，将生成 `frontend/dist` 静态资源产物目录。
2. 在宝塔面板【网站】->【PHP/静态项目】中新建站点，域名填写你的公网域名或服务器 IP。
3. 将站点的【网站根目录】指向刚才上传的 `dist` 目录。
4. 打开该站点的【设置】->【配置文件】，在 `server` 块内配置单页应用（SPA）路由回退与后端 API 反向代理：
   ```nginx
   server {
       listen 80;
       server_name your-domain.com; # 替换为你的域名或IP
       root /www/wwwroot/moyu-frontend/dist;
       index index.html;

       # 1. 支持前端 React Router SPA 路由无刷新回退
       location / {
           try_files $uri $uri/ /index.html;
       }

       # 2. 将 /api/ 接口请求反向代理到本地 8080 后端服务
       location /api/ {
           proxy_pass http://127.0.0.1:8080/api/;
           proxy_set_header Host $host;
           proxy_set_header X-Real-IP $remote_addr;
           proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
           proxy_set_header X-Forwarded-Proto $scheme;
           proxy_connect_timeout 60s;
           proxy_read_timeout 60s;
       }

       # 静态资源强缓存优化
       location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2)$ {
           expires 30d;
           add_header Cache-Control "public, no-transform";
       }
   }
   ```
5. 保存并重载 Nginx，在浏览器中即可直接通过你的域名访问。

### 方案 B：传统 Linux 服务器 (Systemd + Nginx)

#### 1. 配置 Systemd 后端守护进程
创建服务单元文件 `/etc/systemd/system/moyu-backend.service`：
```ini
[Unit]
Description=Moyu Calculator FastAPI Service
After=network.target mysql.service

[Service]
Type=simple
User=www-data
WorkingDirectory=/var/www/moyu/backend
ExecStart=/var/www/moyu/backend/venv/bin/uvicorn main:app --host 127.0.0.1 --port 8080 --workers 2
Restart=always
RestartSec=5
EnvironmentFile=/var/www/moyu/backend/.env

[Install]
WantedBy=multi-user.target
```
加载并启动服务：
```bash
sudo systemctl daemon-reload
sudo systemctl enable --now moyu-backend
sudo systemctl status moyu-backend
```

## ❓ 常见问题与排错指南 (FAQ)

### Q1: 启动后端时报错 `ModuleNotFoundError: No module named 'PIL'`
- **原因**：缺少 Pillow 图像处理库，用于生成图形验证码。
- **解决**：在虚拟环境中重新执行 `pip install pillow>=10.0.0`。如果在 Linux 上安装失败，请确保安装了底层开发包（如 `libjpeg-dev`、`zlib1g-dev`）。

### Q2: 验证码图片加载不出或报 500 错误
- **原因**：Pillow 绘制字体时默认使用内置字体，若环境极其受限可能异常。
- **排查**：检查 `backend/app/core/security.py` 中的 `generate_captcha()` 函数，本项目已使用 Pillow 默认内置矢量位图字体，无需依赖系统特定中文字体路径，开箱即用。

### Q3: 为什么刷新网页后出现 404 Not Found？
- **原因**：前端采用了 HTML5 History 路由模式（React Router）。在页面刷新或直接输入 `/user-center`、`/admin` 时，如果 Nginx 未配置 SPA 路由回退，Nginx 会尝试在文件系统中寻找对应子目录。
- **解决**：检查 Nginx 配置中是否包含 `try_files $uri $uri/ /index.html;`。

### Q4: 如何重置超级管理员密码？
- **方式**：直接连接 MySQL 数据库，执行：
  ```sql
  -- 将密码重置为 admin123 对应的预计算 hash，或删除该记录让 main.py 重启时自动重新创建
  DELETE FROM users WHERE username = 'admin';
  ```
  然后重启后端服务，`main.py` 会自动重新创建 `admin` / `admin123` 账号。

### Q5: 为什么修改了月薪后，当天的工资快照没有变化？
- **机制说明**：系统为了保证记账严肃性，每次更新个人打工档案时，会自动联动校准当天的 `daily_salaries` 出勤底薪，并自动根据新底薪重算当日已赚总金额；如果发现未更新，请在个人中心刷新一次即可自动触发校准纠偏。
